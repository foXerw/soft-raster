# 09 — 光照与线性空间

## 这一章要解决什么问题

第 07 章接通了"uv → 纹素颜色"，但画面还是平的：亮度不随表面朝向变，不随视点变，转动物体只是换一张贴图。
这一章把光接进来——漫反射 `N·L`、Blinn-Phong 高光、点光衰减——结束时你应看到**一条高光带**，
按 `3` 在 Gouraud 与逐像素之间切换，亲眼指出带被摊开还是收紧；同时明白线性空间与 sRGB 各管哪一段。

但 M6 的第一件事不是写 shader，是**叫醒休眠接口**。M3 留下的 `Varyings::worldNormal`/`worldPos` 没有任何 shader 读，
`worldPos` 甚至存着物体空间坐标却叫 world；生产侧四处 `normalMatrix` 全是单位阵——包括带旋转的 golden 场景。
正确的逆转置配方一直活在测试夹具里（`tests/unit/test_pipeline_integration.cpp:26-28`），生产代码一处都没有。
**声明了没人读的字段不是中性的，是把 0 读成结论的陷阱**：错误已经发生，只是还没被观测。
证据是 M6.0 把这两个字段的语义改对之后，两份既有 golden **逐字节不变**——没人读，改了也白改（notes §①）。

法线为什么必须走 `(M⁻¹)ᵀ`：要保的是"与表面垂直"，不是"长度是 1"。切向 `t` 满足 `n·t=0`，变换后切向是 `Mt`，
要 `n'·(Mt)=0` 对所有 `t` 成立 ⇒ `n'=(M⁻¹)ᵀn`。均匀缩放下它退化成"归一化就行"，**非均匀缩放才是判别器**：
`scale(2,1,1)` 下朴素变换的 `dot(·,t1')≈2.12`（垂直性丢了），逆转置给 ≈0（第 02 章片段一跑过这组数）。
归一化必须在变换**之后**——乘法会重新改变长度（`src/render/builtin_shaders.cpp:18-20`）。推导与夹具矛盾案见 notes §②。

## 最小片段

### 片段 1：一条扫描线上的 Blinn-Phong 点光源（只用标准库）

公式与 `src/render/shading.h:45-72` 同形。头灯几何：点光跟随眼，平面 `z=0` 上法线恒 `(0,0,1)`。
它一次演示四件事：衰减与 `pow` 的窄带、`Ns=0` 不跳 `pow` 的刷白、`[1,4096]` 钳位边界、Kd 双重相乘与 sRGB 两个方向。

```cpp
// guide09a.cpp — Blinn-Phong 点光源：扫描线上的 N·L/N·H/pow/衰减 + 三个边界。只用标准库。
// 公式与 src/render/shading.h 的 pointGeom/specForLight 同形（float 路径）。编译任挑一行：
//   g++ -std=c++20 -Wall -Wextra -ffp-contract=off guide09a.cpp -o guide09a && ./guide09a
//   cl /EHsc /std:c++20 /W4 guide09a.cpp
#include <cmath>
#include <cstdio>
#include <initializer_list>
struct V3 { float x, y, z; };
static V3 operator+(V3 a, V3 b) { return {a.x + b.x, a.y + b.y, a.z + b.z}; }
static V3 operator-(V3 a, V3 b) { return {a.x - b.x, a.y - b.y, a.z - b.z}; }
static float dot(V3 a, V3 b) { return a.x * b.x + a.y * b.y + a.z * b.z; }
static V3 normalize(V3 v) {                       // 零向量约定：零长/NaN ⇒ 零向量
    const float l = std::sqrt(dot(v, v));
    return l > 0.0f ? V3{v.x / l, v.y / l, v.z / l} : V3{0.0f, 0.0f, 0.0f};
}
struct Geom { V3 L; float ndl, att; };
static Geom pointGeom(V3 N, V3 P, V3 lp, float r, bool attOn) {
    const V3 toL = lp - P;
    const float d = std::sqrt(dot(toL, toL)), ndl = dot(N, normalize(toL));
    float att = 1.0f;
    if (attOn) { const float t = d / r; att = 1.0f / (1.0f + t * t); }   // 1/(1+(d/r)²)
    return {normalize(toL), ndl > 0.0f ? ndl : 0.0f, att};               // 背光钳 0
}
static float spec(V3 N, Geom g, V3 V, float ks, float I, float ns) {
    if (!(g.ndl > 0.0f)) return 0.0f;             // 背光门：不照这个面的灯不许出高光
    const float ndh = dot(N, normalize(g.L + V)); // 半向量必须归一化，N·H 才是 cosθ
    if (!(ndh > 0.0f)) return 0.0f;               // 也挡 powf(负数,非整数)=NaN
    return ks * I * g.att * std::pow(ndh, ns);
}
static bool specActive(float ns) { return ns > 0.0f; }   // 0/负/NaN 全跳过 pow
static float clampNs(float ns) { return ns < 1.0f ? 1.0f : (ns > 4096.0f ? 4096.0f : ns); }
int main() {
    const V3 N{0, 0, 1}, lp{0, 0, 2}, eye{0, 0, 2};      // 头灯：点光跟随眼
    const float r = 2.0f, ks = 0.35f, I = 0.4f, ns = 64.0f;
    std::printf("== 扫描线 P(x)=(x,0,0)，N=(0,0,1)，光/眼=(0,0,2)，r=2，Ks=0.35 I=0.4 Ns=64 ==\n");
    std::printf("     x      d    NdotL   NdotH  pow(ndh,64)    att       spec\n");
    for (float x : {-1.5f, -1.0f, -0.5f, 0.0f, 0.5f, 1.0f, 1.5f}) {
        const V3 P{x, 0, 0};
        const Geom g = pointGeom(N, P, lp, r, true);
        const V3 V = normalize(eye - P), toL = lp - P;
        const float ndh = dot(N, normalize(g.L + V));
        std::printf("%6.2f  %6.4f  %6.4f  %6.4f  %11.5g  %6.4f  %10.5g\n",
                    (double)x, (double)std::sqrt(dot(toL, toL)), (double)g.ndl, (double)ndh,
                    (double)std::pow(ndh, ns), (double)g.att, (double)spec(N, g, V, ks, I, ns));
    }
    std::printf("== Ns=0：pow(x,0)==1 会把整片受光面刷白 ==\n");
    for (float x : {-1.5f, 0.0f, 1.5f}) {
        const V3 P{x, 0, 0};
        const Geom g = pointGeom(N, P, lp, r, true);
        const V3 V = normalize(eye - P);
        const float ndh = dot(N, normalize(g.L + V));
        const float ok = specActive(0.0f) ? spec(N, g, V, ks, I, clampNs(0.0f)) : 0.0f;
        const float bug = ks * I * g.att * std::pow(ndh, 0.0f);          // 不跳 pow 的写法
        std::printf("x=%5.2f  跳过⇒%.6f  不跳⇒%.6f（=Ks·I·att，与 N·H 无关）\n",
                    (double)x, (double)ok, (double)bug);
    }
    std::printf("== Ns 钳位 [1,4096]：N·H 要挑得让边界可观测 ==\n");
    std::printf("N·H=0.9999：Ns=1e6 不夹 %.6g  vs 夹到 4096 %.6g\n",
                (double)std::pow(0.9999f, 1e6f), (double)std::pow(0.9999f, 4096.0f));
    std::printf("N·H=0.5：   Ns=0.5 不夹 %.6g  vs 夹到 1    %.6g\n",
                (double)std::pow(0.5f, 0.5f), (double)std::pow(0.5f, 1.0f));
    std::printf("== D26：被调方乘 Kd；调用方再预乘一次 ⇒ Kd² ==\n");
    std::printf("传基础色：kd=albedo×Kd=%.3f；预乘后再传：kd=(albedo×Kd)×Kd=%.3f\n",
                (double)(0.5f * 0.5f), (double)(0.5f * 0.5f * 0.5f));
    std::printf("== sRGB：encode(0.5) 与 decode(0.5) 不是同一个数 ==\n");
    const float enc = 1.055f * std::pow(0.5f, 1.0f / 2.4f) - 0.055f;
    std::printf("encode(0.5)=%.6f ⇒ 字节 %d；decode(0.5)=%.4f\n", (double)enc,
                (int)std::lround(enc * 255.0f), (double)std::pow((0.5f + 0.055f) / 1.055f, 2.4f));
    return 0;
}
```

### 片段 2：Gouraud vs 逐像素——网格密度决定带可不可见

1D 角空间类比：正对眼的球面带上 `N(θ)=(sinθ,0,cosθ)`，头灯 `L=V=+z` ⇒ `N·H=cosθ`。
逐像素每点重算 `cos^64`；Gouraud 只在顶点经度采样再线性插值。顶点经度与生产夹具同参
（`θ_j=(j−slices/4)·360/slices`，正对眼在 `j=slices/4`）。**这不是生产渲染**：像素级数字在下面"指回本仓库"节给命令。

```cpp
// guide09b.cpp — Gouraud vs 逐像素：网格密度决定高光带被摊开还是可见。只用标准库。
// 1D 模型：正对眼的球面带上 N(θ)=(sinθ,0,cosθ)，头灯 L=V=+z ⇒ N·H=cosθ。
// 逐像素 spec(θ)=Ks·I·cos^Ns(θ)；Gouraud 在顶点经度采样完整高光再线性插值。
// 顶点经度与生产夹具同参：θ_j=(j−slices/4)·(360/slices)，正对眼在 j=slices/4
//（slices 被 4 整除才有顶点正对眼 —— golden_scene.h 的 static_assert 钉奇数）。
// 这是角空间类比，不是生产渲染；生产的像素级数字来自 test_golden_lit（章内给命令）。
// 编译任挑一行：
//   g++ -std=c++20 -Wall -Wextra -ffp-contract=off guide09b.cpp -o guide09b && ./guide09b
//   cl /EHsc /std:c++20 /W4 guide09b.cpp
#include <cmath>
#include <cstdio>
static constexpr float kPi = 3.14159265358979f;
static float specAt(float deg, float ks, float I, float ns) {
    const float c = std::cos(deg * kPi / 180.0f);
    return c > 0.0f ? ks * I * std::pow(c, ns) : 0.0f;
}
static float gouraudAt(float deg, int slices, float ks, float I, float ns) {
    const float sp = 360.0f / (float)slices, off = deg / sp + (float)slices / 4.0f;
    const float j0 = std::floor(off), t = off - j0, th0 = (j0 - (float)slices / 4.0f) * sp;
    return specAt(th0, ks, I, ns) * (1.0f - t) + specAt(th0 + sp, ks, I, ns) * t;
}
struct Peak { float value, theta, width; };
template <typename F> static Peak scan(F f) {
    const float step = 0.02f;
    float best = -1.0f, bt = 0.0f;
    for (float t = -40.0f; t <= 40.0f; t += step) { const float v = f(t); if (v > best) { best = v; bt = t; } }
    float lo = bt, hi = bt;                       // 半高宽：从峰向两侧走到 < 峰/2
    while (lo > -40.0f && f(lo - step) >= best / 2.0f) lo -= step;
    while (hi < 40.0f && f(hi + step) >= best / 2.0f) hi += step;
    return {best, bt, hi - lo};
}
int main() {
    const float ks = 0.35f, I = 0.4f, ns = 64.0f;  // litDefaultMaterialShade × 默认点光强
    const float ha = std::acos(std::pow(0.5f, 1.0f / ns)) * 180.0f / kPi;
    std::printf("Ns=64 高光带半高半角 = acos(0.5^(1/64)) = %.2f°（全宽 %.2f°）\n", (double)ha, (double)(2.0f * ha));
    const Peak p = scan([&](float t) { return specAt(t, ks, I, ns); });
    std::printf("逐像素      峰 %.4f @ %5.2f°  半高宽 %5.2f°\n", (double)p.value, (double)p.theta, (double)p.width);
    const int cfg[3][2] = {{12, 15}, {24, 31}, {6, 8}};
    for (auto& c : cfg) {
        const int stacks = c[0], slices = c[1];
        const Peak g = scan([&](float t) { return gouraudAt(t, slices, ks, I, ns); });
        const float sp = 360.0f / (float)slices;
        const float near = (std::round((float)slices / 4.0f) - (float)slices / 4.0f) * sp;
        std::printf("Gouraud %2d/%2d 峰 %.4f @ %5.2f°  半高宽 %5.2f°  三角形 %.1f°×%.1f°，最近顶点偏眼 %.2f°\n",
                    stacks, slices, (double)g.value, (double)g.theta, (double)g.width,
                    180.0 / stacks, (double)sp, (double)near);
    }
    std::printf("判据：三角形角尺寸 > 带半宽 %.2f° ⇒ 摊开可见（12/15 的 15°×24°）；\n", (double)ha);
    std::printf("      24/31 的 7.5°×11.6° 比带还小 ⇒ Gouraud≈逐像素（生产实测半高宽 10 vs 10，断言空转）；\n");
    std::printf("      slices%%4==0 ⇒ 顶点正对 N·H=1 的峰，峰位/峰值对照的前提失效（6/8 行）。\n");
    return 0;
}
```

## 指回本仓库：生产版本多了什么、为什么

**数据边界**（`src/render/lights.h`）：`LightRig` 每帧一份（:14-25），`MaterialShade` 逐组一份（:31-38）——
只有 diffuse/ambient/specular/shininess 四个数，**不传 `Material*`**：loader 的类型带着 name/diffuseMap，着色层不该读（A1）。
VS/FS 经 uniforms 里的**指针**共享同一份对象（`src/render/pipeline.h:41-42、81-82`，D15 单一真源），不是两份拷贝。
程序几何的 lit 默认 `litDefaultMaterialShade()`（`lights.h:46-53`）：Ks=0.35、Ns=64、Ka=0.02——
不能沿用 MTL 默认 Ks=0/Ns=0（`src/loader/mtl.h:24-27`），否则 lit golden 烘进一张零高光的球，静默失败。

**数学本体**（`src/render/shading.h`）：两个自由纯函数，可解析单测（D20）。每盏灯的几何（L/N·L/衰减）
只有一份实现 `LightGeom`（:32-57），漫反射与高光都从这里取。`shadeDiffuseOnly`（:81-92）是 ambient+漫反射的**核心**，
被 `shadeBlinnPhong`（:96-114）组合调用——**它不是"Gouraud 那一支"**（Ruling 91，坑 1）。
`Ns` 规则只在一处：`>0` 才进 `pow`（0/负/NaN 全跳过），否则夹 `[1,4096]`（:103-105）。
两道守卫：背光门 `ndl>0`（:66）与 `ndh>0`（:70，兼挡 `powf(负,非整数)=NaN`）。
衰减 `1/(1+(d/r)²)`（:52-54）；`Ka` 环境项 = `rig.ambient × mat.ambient`（:88），是背光面/退化法线上唯一的光——暗，不是黑洞。

**Shader**（`src/render/builtin_shaders.cpp`）：MVP 与 varying 填法共用 `clipFromPosition`（:13-30），
`worldPos` 是真世界空间（:24，此前错赋物体空间且没人读）。`lambertVS`（:61-83）：`lights/mat==nullptr` 早退（:65）；
albedo 只传顶点色（:73），调**完整** `shadeBlinnPhong`（:78-79），结果写进已有的 `v.color` 槽（:81，D6：仍是 12 float）。
`lambertPerVertexFS`（:85-90）一行直读插值结果，**不读 texture/baseColor**——Gouraud 下贴图"消失"是设计（D17，`builtin_shaders.h:44-48`）。
`blinnPhongPerPixelFS`（:92-117）：无光委托 `texturedFS`（:98，D27）；albedo 是纹素或白、**未乘 Kd**（:106-110，D26）；
采样带 `gradU/gradV`（:108，丢梯度 mip 静默退到 level 0）；插值法线必须再 `normalize`（:114，弦短于弧；
丢掉它点积按缩短比例变小，方向光下恰退化成 Gouraud）。

**线性空间**：所有光照运算在线性域，每种输入在进站那一刻解码**一次**，FS 输出只在写颜色目标那一刻编码一次
（`src/render/render_backend.cpp:117`，`FragmentOutput` 的唯一编码点；背景/HUD/sink 各自编码自己的线性值，同样只一次）。

| 输入 | 解码发生在 | 位置 |
|---|---|---|
| 光色（CLI sRGB 浮点） | `buildLightRig` 经 `decodeLightColor` | `src/app/scene.cpp:113`、`lights.h:58-60` |
| MTL 的 Kd/Ka/Ks | **解析时** | `src/loader/mtl.cpp:118` |
| 纹素 | **采样时**，由 `Texture::srgb` 门控 | `src/render/sampler.cpp:60-66` |
| 顶点色 | 无——程序几何直接在线性域创作 | `src/scene/mesh.cpp:195` |

Kd 解析时 vs 纹素采样时的不对称是有意维持的（加载时解码 ×4 内存、mip 平均会在编码空间做、数据纹理不该解码；notes §④）。
编码曲线是 IEC 分段（`src/render/color.cpp:10-14`，接缝 0.0031308）：线性 0.5 → `1.055·0.5^(1/2.4)−0.055=0.735357` → 字节 **188**。
法线视图 `debugNormalFS` 输出线性 `(N+1)/2`、FS 内不编码（`builtin_shaders.cpp:124-127`），出口恒编码 ⇒ 0.5 变 188 不是 128——
这是输出侧单一编码点的**正确后果**；`Texture::srgb=false` 管的是**输入侧**解不解码，两件事别混（`builtin_shaders.h:73-76`）。
法线是普通 FS 视图，深度/灰度才是帧末 sink（`src/app/view_mode.cpp:8-24`，D23）。

**app 接线**：11 个旗标（10 个光参数 + `--shade`，`src/app/cmdline.cpp:360-369`）。越界在**解析期**拒：
颜色分量 `[0,1]`（:222-229）、方向/坐标必须有限（:235-242）、可步进强度 `[0,3]`（:253-256）、衰减半径 `>0`（:269-270）。
为什么在门口拦：命令行是明确表达的意图，下游 `srgbToLinear` 会**静默改写**（`--key-color 2 0 0` 变 `1 0 0`）；
`--point-pos nan` 曾合法 ⇒ `att=NaN` ⇒ `0*NaN=NaN` ⇒ clamp 成 0 ⇒ 整个模型全黑、无诊断（:230-234 注释）。
运行时夹钳 `[0,3]` 是按键步进的边界，不是改写命令行的理由。按键译码在 `src/app/win32_window.cpp:249-257`，
消费在 `src/app/main.cpp:425-447`：`3` 循环 PHONG→GOURAUD→UNLIT（`scene.cpp:154-161`），`[`/`]` 点光、`-`/`=` 主光各 ±0.1，
`A` 切衰减，`0` 恢复**启动基线**而非内置默认（`scene.cpp:169-175`，R99）。加法步进保证 0 可达（D24，`scene.cpp:138-143`）。

**生产数字**（命令：`./build/Debug/soft_raster_tests.exe --only gouraud_smears_the_specular_peak`）：
`[lit7b] 全局峰 P=0.1366@(159,89) G=0.0876@(162,76)；点瓣半高宽 P=10 G=13；半高面积 P=121 G=181`。
高光隔离 = linear(full) − linear(Ks=0 对照)，半高宽在**线性**域量；阈值宽比 ≥1.25、面积比 ≥1.3（`tests/unit/test_golden_lit.cpp:452-456`）。
峰位随眼动（#7c）、边界 kink（#8，不叫 Mach band——那是感知过冲，测的是二阶差分）见 notes §③。
这些逐像素 pow 断言只在 MSVC 判定，g++ 侧可见 `[skip]`（`test_golden_lit.cpp:3-7`）。
帧时间 A/B（Release、12 三角形场景）：gouraud 3.20 / unlit 6.10 / phong 10.65 ms/帧——gouraud 比 unlit 快因为 FS 不采样；
数字与测量条件见 notes §⑤，本章未复跑，且不许外推到几何密集场景。

## 坑（一手来自 docs/notes/M6-光照与休眠接口.md）

1. **Gouraud 只算漫反射 = 验收目标空转**（Ruling 91）。保留 Gouraud 的唯一理由是观察高光带被摊开；
   没有高光的 Gouraud 没有带可摊开，对照退化成"没有 vs 有"。教科书 Gouraud 本就在顶点算**完整**光照。
   连带：`shadeDiffuseOnly` 必须被组合调用，否则它自己就成了本章谴责的休眠函数。
2. **albedo 与 diffuse 双重相乘**（D26/Ruling 93）。契约定在**被调方乘 Kd**（`shading.h:86`），调用方只传基础色。
   简报字面"albedo=顶点色×diffuse"照做会得 Kd²：M6.3 的 TDD 靠 `0.125≠0.25` 当场抓出。
   一般化：两个"看起来同义"的参数名，谁乘谁必须在签名处写死。
3. **D27 等式测试结构上抓不到丢梯度**。`lights=nullptr` 的等式走 unlit 委托，lit 分支的 `sample()` 一行没跑——
   丢梯度变异在那里不可能红（第一轮实测存活）。修法：加一条 **lit 分支**的缩小等式腿（Kd=1、N·L=1 ⇒ lit 输出=纹素），
   配 64×32 非方形贴图（rho≈10 ⇒ level 3，与 level 0 必须不同）（`tests/unit/test_lit_shaders.cpp:1083-1084、1128-1147`）。
4. **"逐像素峰严格大于 Gouraud 峰"是假的**（notes §③）。饱和 clamp 让两张图峰值都成 255；头灯几何下偶数 slices
   让峰恰好落在顶点上。凸组合真正预言的是"能量摊开"，所以比**宽度与位置**，不比最大值。
5. **密度是断言的前提，不是旋钮**（notes §③）。24/31 细网格半高宽 10 vs 10 空转；10/13 更粗时 Gouraud 自身半高宽反缩到 9；
   12/15 是分离区间。`src/scene/golden_scene.h:65-76` 用 static_assert 钉奇数 slices，密度区间写在常量注释里。
6. **休眠字段会咬造它的人**。M6 设计第一版打算在四个恒 0 的 `ms*` 字段上做 A/B 测量（把 0 读成"这阶段不花时间"）。
   `ViewPlan::useFragmentShader` 在 P101 删掉多余三元后失去唯一生产读者，终审裁定删除（提交 `1d32d99`），
   用四帧 `cmp` 证明行为逐位不变（`build/m6_final_a4_identity.log`：phong/unlit/gouraud/lit 全 IDENTICAL）。
7. **sRGB 方向写反**：计划第一版把解码方向当编码方向算出 132 错值；正确是 encode(0.5)→188、decode(0.5)≈0.214（notes §④）。
8. **未执行的验证声称**（Ruling 107）：报告里每条"已验证"必须能在仓库或 build/ 找到原始输出，找不到就标"未验证"。
